# VSCode DeepSeek Harness 插件（Sidebar）PRD

![首页界面](<png/屏幕截图 2026-08-15 000731.png>)

## 1. 背景与目标

为 deepseek-harness（dsh）开发一个 Codex 风格的 VSCode 插件，主界面位于侧边栏。
插件只负责前端界面，后端完全复用 dsh 的能力（会话、模型、工具、审批、设置）。
最终目标：dsh 网页版具备的能力，插件侧边栏里都能用。

## 2. 产品形态与布局

侧边栏垂直三层结构（见上方首页截图）：

- **上层栏**：Chats 会话列表 + 三个按钮（历史、设置、新建对话）
- **中间层**：对话内容展示区
- **下层栏**：输入区（附件、模型切换、发送等）

单后端（只接 dsh），不做多 agent 标签页。

## 3. 功能需求

### 3.1 上层栏：会话管理

- 会话列表：按当前 VSCode 工程目录（cwd）过滤，只显示本项目的会话；列表项显示状态点、标题、相对时间（如 3d）；超出显示 "View all (N)"
- 状态点优先级：等待审批/提问（琥珀色）> 运行中（绿）> 已完成
- 会话操作：重命名、删除、Fork（从某个已完成回合分叉出新对话）
- 新建对话按钮
- 历史按钮：完整会话列表 / 搜索
- 设置按钮：打开设置面板（见 3.4）

### 3.2 中间层：对话展示区

对话区交互设计整体参考 dsh 网页版（`packages/client/ui-conversation`）：

**消息流渲染**

- 用户消息：右对齐气泡，气泡下方复制按钮 + 时间戳；图片附件缩略图贴在气泡上方
- Assistant 回复：完整 Markdown 渲染（代码块带复制按钮、数学公式、图片）；流式输出期间代码块/公式先按纯文本显示，回合结束后完整渲染；被中断的回复带 "Stopped" 标记
- Think（推理）块：单行折叠行（图标 + "Think" + 摘要），流式中摘要自动跟随最新一行，点击展开全文
- 工具调用：**默认全部折叠为单行**（工具图标 + 工具名 + 摘要，错误显示红点 + 错误首行）；整行点击展开为卡片，按工具类型区分：
  - Bash → 终端卡（命令 + stdout/stderr + 退出码）
  - Edit/Write → diff 卡
  - Read → 带行号的文件内容卡
  - Grep/Glob → 搜索结果卡
  - Web 搜索 → 引用列表卡
- Subagent 产生的工具调用递归缩进展示；会话头部显示 "N subagents" 入口，可进入子会话查看
- 特殊行：上下文注入（AGENTS.md 等）折叠行、历史压缩标记（"Compacted N history items"）、模型重试行（"重试 2/5，约 30s 后"）、回合错误（红点 + 错误码）、token 上限提示
- 运行状态行：回合进行中显示 "Deep diving..." 状态，超过 15 秒附加已运行时长
- 消息操作：复制、点赞/点踩（可附文字反馈）、Fork 分支
- 回合尾部统计：`时间 · Ran for 15s · TTFT 1.2s · 34 tok/s`

**审批与提问（核心交互：接管输入区）**

- 审批请求：pending 时整个输入区被审批面板替换——琥珀色 "Waiting for approval" 顶条 + 模型理由 + 待执行命令 + **Refuse / Allow once** 按钮；点击后等待后端确认再恢复输入栏
- Ask-user 提问：同样接管输入区——问题标题 + 选项列表（单选 radio / 多选 checkbox，推荐项带徽章）+ 自定义输入行 + 上一题/下一题分页 + Skip / Submit
- Plan 评审：接管输入区——完整计划 Markdown 渲染 + **Chat about it / Refuse / Approve** 三按钮

**滚动行为**

- 贴底自动跟随，用户上翻即解除跟随；离开底部时浮现"回到底部"按钮；历史分页顶部 "Load older"

### 3.3 下层栏：输入区（Composer）

整体参考 dsh 网页版 InputBar，圆角卡片形态：

- 文本框：多行自动增高（2 行起、上限 14 行内滚）；Enter 发送、Shift+Enter 换行；支持 `/` 技能命令、`@` 引用；运行中可选择"排队发送"或"立即插话"
- 附件：`+` 按钮 + 拖拽 + 粘贴图片；附件缩略图 rail 显示在卡片顶部，可预览、可移除；超限整批拒绝并提示
- 左下：命令菜单（`+`）、权限模式选择器（Read Only / Workspace Write / Full access，选 Full access 弹风险确认框）、Plan 模式开关
- 右下：模型选择器（两级菜单：模型按 provider 分组 + reasoning effort 档位，触发按钮显示 `模型名 · effort`）、上下文用量环（N% of context used）、主按钮（静止=发送箭头，运行中=方块 Stop）
- 消息队列：运行中发送的消息进入队列，显示在输入框上方，可编辑/删除/立即插话（Steer）
- Todo 面板：agent 使用 todo 工具时，任务清单显示在输入框上方
- Goal 条：有目标时输入框上方显示目标状态条（active/paused/blocked + 暂停/编辑/清除）
- 统计行：输入卡片下方一行小字（turns/steps、LLM 耗时、TTFT、tok/s、缓存命中、token 用量）

### 3.4 设置

设置项对齐 dsh 网页版设置（模态面板 + 左侧导航）：

- **通用**：Agent 预设、新会话默认权限模式、语言（中/英）、外观（跟随 VSCode 主题/浅色/深色）、繁忙时 Enter 行为（排队/插话）
- **模型**：provider 列表（已配置/未配置状态）、编辑卡（API key、base URL）、添加提供方/自定义提供方、删除（先删凭证再删配置，需确认）
- **插件**：可配置插件设置 + 插件清单
- **Agent 预设**：预设列表管理

凭据（API key）通过插件界面编辑，写入 harness 凭据存储。

## 4. 会话归属

不引入网页版的 workspace 概念。插件直接以当前 VSCode 工程根目录（cwd）作为会话归属：
打开插件即显示该目录下的会话，新建会话也以该目录为工作目录运行。

## 5. 后端接入（技术约束）

- 插件连接本机 dsh 服务（loopback），无实例时自动拉起，用户无感
- 复用 dsh 的 Web Host 接口（会话/模型/设置/审批等 RPC + 事件流），不重写后端逻辑
- 适配当前 dsh 版本（0.1.0-rc 系），版本不匹配时提示用户升级，不做多版本兼容
- 前端为 VSCode webview 内 React 应用；界面设计风格对齐 dsh 网页版，主题默认跟随 VSCode

## 6. 非功能需求

- 本地使用（VSIX 安装），不发布插件市场
- 中文界面文案（对齐 dsh 网页版语言设置）

## 7. 优先级与里程碑

- **P0（可用闭环）**：新建对话、会话列表与恢复、消息流渲染（Markdown/Think/工具调用）、输入发送、模型切换、审批交互、权限模式切换
- **P1（完整体验）**：附件、消息队列与插话、ask-user 提问、Plan 评审、会话重命名/删除/Fork、搜索、设置页（通用 + 模型）
- **P2（对齐网页版）**：Todo 面板、Goal 条、统计行、Trajectory 视图、点赞点踩反馈、设置页（插件 + Agent 预设）、onboarding 引导

## 8. 范围外

- 多 agent 聚合（Claude Code / Codex 等其他后端）
- 远程 harness 连接（仅本机 loopback）
- 网页版的 workspace 注册表管理 UI
- 插件市场发布
